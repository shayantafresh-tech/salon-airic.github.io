# GitHub Pages static upload

Upload the **contents of this folder** to the root of a GitHub repository, then enable GitHub Pages for the repository.

This is a static-only build. Team selection, player profiles, hall schedule, gallery, and browser-local announcements are included. Login, shared RSVP voting, shared player ratings, and shared rank updates require a server/API and are not available on GitHub Pages alone. Data saved in localStorage stays only in the visitor's browser.

Do not add private credentials or account files to a public repository.
